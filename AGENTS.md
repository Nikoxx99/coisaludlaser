# Project guidance

Before writing or editing patient-facing copy, read `docs/guia-comunicacion-angie-lezama.md`. Match the documented voice of Dra. Angie Lezama and distinguish historical campaign language from current business facts. Keep service data, availability, professional assignments and booking visibility sourced from the TuOdonto API.

For Next.js changes, consult the relevant installed documentation under `node_modules/next/dist/docs/`. Run `pnpm typecheck` and lint the changed source files. The website installs and deploys independently from the TuOdonto repository.

Use Pencil tools exclusively to inspect or modify `frontend.pen`; never read or edit its serialized file directly.
